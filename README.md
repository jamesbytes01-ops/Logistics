# TrinitySecurityHub.com — Official Website & Software Retail

Production-grade website and Webroot cybersecurity software retail portal for **TrinitySecurityHub.com**, owned and operated by **Trinity Logistics Solutions, LLC**.

## Corporate Information

- **Company Name:** Trinity Logistics Solutions, LLC
- **Registered Address:** 345 Marshall Avenue, Saint Louis, MO 63119, United States
- **Operations:** Commercial logistics & transportation coordination discussions and authentic Webroot cybersecurity software retail distribution.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Frontend:** React with TypeScript
- **Styling:** Vanilla CSS & CSS Modules (no external CSS frameworks)
- **State Management:** React Context (Shopping Cart with localStorage persistence)
- **Deployment:** Cloudflare Workers

## Features

- **Commercial Logistics Presence:** Informational overview of freight transportation coordination, distribution logistics, and operational values based in Laredo, TX.
- **Dedicated Webroot Store (`/shop`):** 15 verified, distinct Webroot software product subscriptions with detailed specs, feature tables, and FAQs.
- **Cart & Order Review:** Full shopping cart capabilities, quantity management, subtotal calculation, and transparent order request review.
- **Corporate Transparency:** Dedicated legal and support pages including Terms, Privacy Policy, Refund Policy, Subscription Policy, Technical Support, and FAQ.
